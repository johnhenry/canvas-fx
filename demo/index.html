pixelable

A live gallery of @johnhenry/pixelable, each demo running the real source from ../src/ in its own iframe. List effects on a pixel-canvas like CSS filter (effects="mosaic(4) palette(gameboy, ordered)"), or wrap the source in effect elements.

pixel-canvas

Every built-in effect, a custom one, sprites, shaders, and a live camera you can restyle.

pixel-canvas: GPU, pointer, transitions, chaining, recording

Whole chains as shaders (gpu), a lens and a spotlight that follow the pointer, animated changes between looks, one canvas feeding another, and saving the result as a GIF or video.

pixel-glyphs: the image as text

Colored characters, a green terminal, line art by shape, live HTML as text, and toText() giving it back as a string.

Live HTML experimental

pixel-canvas html

Live HTML through the effects: a terminal typing itself and a form you can still use. Needs HTML-in-canvas (chrome://flags/#canvas-draw-element); elsewhere the HTML shows as it is.

Every card imports directly from this repo's src/: open this page through a static file server (npm run serve, then /demo/).
